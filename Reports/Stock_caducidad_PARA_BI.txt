1) REGLA DE NEGOCIO (OBLIGATORIA)
---------------------------------
Fuente unica: bc.[Item Ledger Entry]

Filtro fijo:
  - Open = 1
  - Remaining Quantity = 1   <<-- esto es "Cajas pendientes = 1"

Stock disponible = campo [Kilos] de la misma linea ILE.
NO usar Inventory / Value Entry / otras tablas para el stock.


2) SEMAFORO / ESTADO CADUCIDAD
------------------------------
Calculado respecto a HOY (GETDATE):

  Caducado            -> dias < 0
  Proximo a caducar   -> dias entre 0 y 7
  En seguimiento      -> dias entre 8 y 15
  Correcto            -> dias > 15
  Sin fecha           -> Expiration Date vacia o year < 1900

Colores sugeridos (Stolt):
  ROJO     RGB(192,0,0)      Caducado
  NARANJA  RGB(237,125,49)   Proximo a caducar
  AMARILLO RGB(255,192,0)    En seguimiento
  VERDE    RGB(84,130,53)    Correcto
  GRIS     RGB(127,127,127)  Sin fecha


3) QUERY SQL (Power Query / Dataset / Fabric / SSAS)
----------------------------------------------------
-- Archivo tambien en: sql\stock_ile.sql

SELECT
    ile.[Location Code] AS Almacen,
    ile.[Item No.] AS Item,
    ile.[Description] AS Producto,
    CAST(ile.[Kilos] AS float) AS [Stock disponible (kg)],
    CAST(ile.[Fecha despesque] AS date) AS [Fecha despesque],
    CAST(ile.[Fecha empaque] AS date) AS [Fecha empaque],
    CASE
        WHEN ile.[Expiration Date] IS NULL OR YEAR(ile.[Expiration Date]) < 1900 THEN NULL
        ELSE CAST(ile.[Expiration Date] AS date)
    END AS [Fecha caducidad],
    CAST(ile.[Remaining Quantity] AS float) AS [Cajas pendientes],
    CASE
        WHEN ile.[Expiration Date] IS NULL OR YEAR(ile.[Expiration Date]) < 1900 THEN NULL
        ELSE DATEDIFF(day, CAST(GETDATE() AS date), CAST(ile.[Expiration Date] AS date))
    END AS [Dias restantes],
    CASE
        WHEN ile.[Expiration Date] IS NULL OR YEAR(ile.[Expiration Date]) < 1900 THEN N'Sin fecha'
        WHEN DATEDIFF(day, CAST(GETDATE() AS date), CAST(ile.[Expiration Date] AS date)) < 0 THEN N'Caducado'
        WHEN DATEDIFF(day, CAST(GETDATE() AS date), CAST(ile.[Expiration Date] AS date)) <= 7 THEN N'Proximo a caducar'
        WHEN DATEDIFF(day, CAST(GETDATE() AS date), CAST(ile.[Expiration Date] AS date)) <= 15 THEN N'En seguimiento'
        ELSE N'Correcto'
    END AS [Estado caducidad]
FROM bc.[Item Ledger Entry] AS ile
WHERE ile.[Open] = 1
  AND ile.[Remaining Quantity] = 1;


4) AGREGADO PARA DASHBOARD POR ALMACEN (como el Excel)
------------------------------------------------------
En Power BI / DAX o en SQL, agrupar por:

  Almacen + Item + Producto + Fecha despesque + Fecha caducidad + Estado caducidad

Medidas:
  Cajas = SUM( [Cajas pendientes] )   -- cada linea ILE filtrada vale 1
  Kg    = SUM( [Stock disponible (kg)] )
  Lineas / productos distintos segun haga falta

Filtro tipico de paginas BI:
  Almacen IN ( "E", "G", "J", "V3", "W" )


5) MEDIDAS DAX DE EJEMPLO (cuando montes el modelo)
--------------------------------------------------
Cajas =
SUM ( StockILE[Cajas pendientes] )

Kg =
SUM ( StockILE[Stock disponible (kg)] )

Cajas caducadas =
CALCULATE ( [Cajas], StockILE[Estado caducidad] = "Caducado" )

Cajas proximas =
CALCULATE ( [Cajas], StockILE[Estado caducidad] = "Proximo a caducar" )

Cajas en seguimiento =
CALCULATE ( [Cajas], StockILE[Estado caducidad] = "En seguimiento" )

Cajas correctas =
CALCULATE ( [Cajas], StockILE[Estado caducidad] = "Correcto" )

% Caducado =
DIVIDE ( [Cajas caducadas], [Cajas] )
